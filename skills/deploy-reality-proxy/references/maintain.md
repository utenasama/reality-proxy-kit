# 维护与恢复

读工具包 `docs/operations.md`，核对当前管理模式和部署 receipts。core 本地状态是权威；panel 每次从在线原生数据快照开始。面板模式不得拿旧 controller accounts 当业务真相。

账户支持创建、启停、删除、轮换和明确路线授权。没有限流、计费或无感踢线承诺。变更可能重启入口，告知现有连接中断；验证新连接权限。

诊断默认本地脱敏报告，不自动上传。错误机器、漂移、内核哈希不符、缺失兼容开关、冲突端口、未知已有代理均应停止对应部署，不清空重装来掩盖异常。

备份保存在控制端，AES-GCM 认证加密，解密密钥单独保管。panel 必须包含实际 SQLite 一致快照；关键迁移前备份。恢复先解密到新私有目录，再配置空白候选；不能覆盖在线数据库或重新初始化身份。

单机转链式应停用旧 direct 路线并创建新链式路线，不改变旧 route number 的含义。core 转 panel 明确移交权威，保留账户/入口/订阅身份。不同管理模式不是可互换的恢复格式。

发布状态写未验收的能力只能按候选流程验证，不承诺生产可用。没有目标资源时继续离线配置/测试并记录缺口；不把作者生产机器作为备用测试环境。
